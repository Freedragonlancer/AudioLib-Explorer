资源限制

客户端连接

客户端「服务器地址」填下面其中一个（只填到端口或路径前缀，不要加 /api/v1）。

公网地址

外网客户端使用的地址，例如 https://audiolib.example.com:8443，可带路径前缀（如 https://example.com/audiolib）。由反向代理转发到本机 8790 端口；反代要求见 API 文档「外网反代要求」。保存后 /api/v1/health 的 public_url 立即更新。

原生 HTTPS（可选）

一般用反向代理提供 HTTPS，这里不用填。若要服务端自己监听 HTTPS：填证书链 PEM、私钥 PEM 的绝对路径和端口（如 8791），8790 的 HTTP 照常。保存前会校验文件，保存后立即生效，无需重启。注意：本版本客户端只信任公共 CA 签发的证书（如 Let's Encrypt），自签名证书客户端不会接受。

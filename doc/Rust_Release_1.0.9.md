# AudioLib Explorer 1.0.9 发布记录

正式版于 2026-11-19 22:33:03 UTC（北京时间 2026-11-20 06:33:03）发布，七份归档和十四项资产已核验。 [正式发布](https://github.com/Freedragonlancer/AudioLib-Explorer/releases/tag/v1.0.9)

## 候选范围与 Beta 验收

本版以 1.0.8 为 PATCH 基线。接口与资料库格式仍为 API `/api/v1/`、本地写 schema 8、显式服务端迁移 schema 9、只读快照 `3..=9`。[#369](https://github.com/Freedragonlancer/AudioLib-Explorer/pull/369) 交付 Classic 和 Studio 的紧凑资料库行、音高和速度弹窗、音量与输出状态对齐，以及工作区页签分隔线。[#370](https://github.com/Freedragonlancer/AudioLib-Explorer/pull/370) 冻结 Beta `528214ddf13e19d94d5dff029248ca5bdf5ff48f`，源码树为 `62b43fad525d39111c75bd7d2cb123f190df9603`。

[#369](https://github.com/Freedragonlancer/AudioLib-Explorer/pull/369) 的严格桌面 Clippy 和 15 项定向回归沿用原始提交 `5b8d212` 的身份。版本准备只调整工作区版本、锁文件版本记录和发布说明。有效桌面实现、第三方依赖版本和工具链与冻结候选一致。

Mac Beta 原生服务端构建、打包、验收分别耗时 62.6、13.4、10.3 秒。使用验收过的服务端与迁移器刷新 Beta，健康、服务提交、配置根读取 1/1 和部署哈希均通过，刷新耗时 178.2 秒。Mac 客户端随后在同一固定 checkout、target、Rust 1.97.1 和 SDK 27.0 上预编译，管线耗时 681.2 秒，Cargo 耗时 678 秒，记录 24 次编译，其中 10 次为工作区 crate。

Windows Beta 以实际交付的 ASIO 配置构建并通过便携包验收和独立安装。构建耗时 1098.3 秒，Cargo 记录 10 条工作区编译和 0 条第三方依赖编译。目录打包、便携验收和 Beta 安装分别为 22.6、18.2、9.8 秒，两份 EXE 哈希绑定候选。

实际 Beta 包在 Classic 和 Studio 两种界面检查了合成 WAV 封面、缺图图标、库名和数量同排显示、紧凑音高和速度控件、音量读数与输出状态。精确输入、滑杆应用、Enter 和 Esc 行为沿用 #369 定向回归。实际 Beta 包使用 ASIO 构建，界面检查使用合成音频和软件渲染。

Windows 对同一候选的远端冒烟耗时 344.7 秒，10/10 通过。完整隔离同步 909,342 条、10,150.7 MiB，用时 144.0 秒，配置根内流读取 20/20。存在 828,780 条记录位于配置根外，与 1.0.8 一致。Mac 预编译后的跟进健康检查返回 HTTP 200。

## Docker 上传恢复策略

1.0.7 最后一份包就绪至公开为 159.0 秒，1.0.8 为 1,422.6 秒。1.0.8 最后一份包比 1.0.7 早 471.2 秒就绪，但标签冻结至公开多 792.4 秒。三次失败 POST 累计占用 1,110.1 秒的工作进程时间。第一次和第二次双路上传的重叠时长合计 687.1 秒，包括失败的尝试。两次补传启动前的空档合计 149.3 秒。[1.0.7 发布记录](Rust_Release_1.0.7.md) · [1.0.8 发布记录](Rust_Release_1.0.8.md)

本次发布协调器保留首轮双路。在归档 POST 发生可识别的临时连接中断时，让已经启动的任务执行完毕，回查同一草稿。若确认资产缺失，当次草稿的 Docker 队列自动切换为单路，只补传缺项。远端已有且身份匹配的资产保留。遇到 `starter` 或身份冲突时暂停。离线模拟覆盖两路断线、保留在途成功资产、远端已收妥、`starter` 冲突、重试上限及恢复后保持单路。

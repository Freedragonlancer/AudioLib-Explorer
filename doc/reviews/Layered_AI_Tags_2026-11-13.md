# 主声音与分层素材推荐（2026-11-13）

基于 beta `34a65fa`，将原来的最多 6 个同色推荐扩展为按真实素材层需求选择 6／8 项，并在界面区分用途。本记录对应开发源码；已安装和已发布的旧产物保留各自的构建身份。

## 行为

“允许分层”表示允许评估独立素材层是否有助于声音设计。云端模型根据描述决定是否给出冲击、低频、碎片等素材层；普通需求可以只返回主声音。离线模式根据匹配配方提供已有素材层，关键词及 UCS 候选仍是主声音。

- 无有效素材层时最多 6 个主声音推荐；至少一项明确分层推荐通过当前资料库命中核验后，主声音与素材层总计最多 8 个，主声音自身仍最多 6 个。
- 不强制填满数量，也不固定主声音与素材层的比例。原始候选仍最多 12 个；1–2 词、最强单词入口和来源校验沿用既有规则。层候选没有结果或与主声音查询重复，不会额外授予扩容名额。
- 主声音用薄荷色、“主／M”标记；素材层用杏色、“层／L”标记。悬停提示、无障碍说明也包含用途；第 8 项与其他项一样支持正文搜索和独立“+”新任务。
- “查询全部”使用当前全部 6／8 项；任务名额不足整批拒绝。生成后自动搜索仍最多 3 项。分层选项在请求途中改变时，旧结果不能发布或自动建任务。

## 契约和兼容

`AiQuery.kind` 明确表示 `main` 或 `layer`，显示名称 `layer` 不用于猜测用途。缺少 `kind` 的旧回复默认 `main`；未知枚举值被拒绝，明确分层必须带非空素材层名称。离线配方及 Jev 本地重建也设置同一类型，缩短、去重和单词置首保留类型及来源。

云端 JSON Schema、Chat 示例及固定约束包含类型。关闭分层时过滤意外素材层项，但过滤前仍验证全部候选的大小、结构和来源。桌面再次按请求时捕获的许可筛选，并依据实际命中后的类型选择上限。同词跨用途只保留一次，优先作为主声音。配置文件、资料库格式和网络资料库 API 不变。

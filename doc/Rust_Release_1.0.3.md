程序 1.0.3 | API /api/v1/ | 本地写 schema 8 | 服务端迁移 schema 9 | 快照兼容 3..=9

2026-11-18 开始发布准备，以正式版 `v1.0.2` 为基线。初始审查 beta 为 `bd1225f44e1bfb476f81930d86e61a22981a663b`。当前尚未发布；最终 main/tag、平台产物、线上资产和固定安装须由完成后的实际收据补齐。

## 范围与兼容

纳入 #321–#325 的系统字体、文字颜色、推荐主题与预设，#326–#327 的 AI 设置／Skill 编辑与本地查看文件，以及 #328 的全局设置滚动和关闭图标修正。API v1、本地写 schema 8、专用服务端写 schema 9、快照读取 3..=9 和完整格式沿用 1.0.2，不新增资料库迁移。

新增 `ai/customization.json` 独立原子保存 Skill 文档和搜索行为，保留原供应商及加密密钥格式。只有已保存且启用的方案参与生成，未保存草稿不发送；文件夹导入和查看副本不执行文档内容。旧转发服务器仍按旧提示词长度校验，超过 2000 字的新 Skill 需要同步升级服务器；64 KiB 请求体上限保留。

## 验证选择与复用

本轮独立 review 发现 P2：Skill 文档实际落盘失败后，保存搜索行为或供应商可清空共用错误，使关闭遗失失败的编辑。修复将新增 customization 操作按 Skill ID、搜索行为、兼容选择和导入隔离，同时保留原供应商／兼容提示词错误；错误先记录再释放保存屏障。明确放弃或删除只解除对应 Skill 的保护。新增真实 Controller 回归在自有目录制造原子保存失败，覆盖同文件／跨文件的无关保存、另一 Skill、无效导入、对应重试与放弃。补修已独立复核，实际检查结果按完成收据补齐。

以 [Rust 验证报告](Rust_Validation.md) 的 2026-11-16／17 外观、AI 设置、Skill 本地目录和设置滚动记录为原始开发基线。按实际源码、feature、工具链、调用方及平台条件核对复用；原失败、修复后通过及 ignored 入口保留各自身份，不把复用结果计为本次新测试。

数据库、扫描、Metadata、音频引擎、IPC 和更新器实现没有改变，相关稳定基线沿用 `v1.0.2` 的原通过身份。新增偏好与 Skill 的持久化、关闭保护和 UI 交互按其实际调用链验证；不因版本号重跑无关 workspace、数据管理或百万条性能套件。需要的原生平台覆盖和最终包验收仍分别执行。

## 交付边界

正式资产合同为七份归档及七份 `.sha256`：Windows x64 客户端和服务端、macOS arm64 客户端和服务端、Linux x64 服务端、Docker linux/amd64 与 linux/arm64。独立 Linux arm64 原生包仅作为 Docker 输入。正式 payload 从最终 main/tag 构建、打包及验收；beta 字节不替代最终身份。

Windows 固定安装继续使用原仓库 `local_release/`，工作数据、配置与库保持原位置。Mac ad-hoc 签名不是 Apple 公证；若 Linux x64 在 ARM64 OrbStack 上仿真，按实际条件明确记录。真实供应商、ASIO 硬件和声学延迟仅按实际测量报告。性能目标仍为 **P95 latency <500ms for 1M+ records**，本版未改变查询性能路径。

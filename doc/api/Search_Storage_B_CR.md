## 数据和恢复边界

审查覆盖 typed business digest、隐式 rowid、signed ID、WITHOUT ROWID、序列水位、未知
扩展、授权退役边界、源绑定、备份、管理/扫描/升级租约、批次与游标提交顺序、发布 receipt、
checkpoint 和完整回滚。最新 v6 授权退役 `play_history`、`play_count` 和 `last_played_at`；本地旧历史须在验证备份后先导入独立 history.db，服务端/快照不导入。
后续业务数据或 DDL 变化会阻止回滚覆盖。未发现其他可确证的数据损坏或恢复缺陷。

进程退出测试覆盖 copy/index 的脏页与热 journal、部分 SQLite backup 发布/回滚及已提交
边界；它们不代表真实断电或所有文件系统故障。未知扩展若不能受控转换会阻止升级。
缓存崩溃残留仍保守保留；重试从旧有效缓存开始，不自动认领或回收其他任务。

合并保留主线的 Waveform 缓存管理、同 revision 写响应、独立下载/解压计数、写盘阶段及取消。
两端发布号来自同一 workspace；版本范围不替代下载后实际库格式检查。
